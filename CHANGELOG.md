# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-09-03

### Added

- Edit local mixed-media sports directories into evidence-backed 16:9 4K or
  1080p Vlogs with mandatory FFmpeg processing and HyperFrames visual direction.
- Release-grade cycling, hiking/non-technical mountain journey, and pool
  swimming profiles, plus experimental contracts for four additional sports.
- Immutable media ingest, activity-data privacy controls, evidence-backed shot
  understanding, original-backed timelines, and protected audio continuity.
- A local review-safe director workbench with one hash-bound approval,
  transactional design/Look lock, Anchor-first asset production, and explicit
  motion ownership.
- Encoded-MP4 inspection, bounded repair, honest `BLOCKED`/`CANCELLED` states,
  and distinct `DELIVERED` and optional `USER_ACCEPTED` semantics.
- Deterministic 100-point release evaluation with cycling, hiking, and pool
  swimming golden projects. Run it with `npm run eval`.
- Tag-gated GitHub Releases containing a deterministic `.skill` archive and its
  SHA-256 checksum after the full release suite passes on the current `main` commit.

### Changed

- Pinned third-party GitHub Actions to immutable commits and upgraded them to
  Node 24-compatible releases so CI remains quiet and supply-chain inputs are auditable.

### For contributors

- Added versioned JSON contracts, Node test suites, synthetic-media checks,
  upstream lineage locks, CI gates, and a deterministic `.skill` packaging and
  publication workflow documented in `RELEASING.md`.
